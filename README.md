# Credit-Debit-Analysis
1. Project Title:
Credit & Debit Analysis

2. Description:
The Credit & Debit Analysis Dashboard is a visually engaging and analytical PowerBI report designed to help users explore and compare the data. Banks generate huge volumes of lending and transaction data. This project turns that raw data into dashboards that help stakeholders monitor portfolio health, repayment, risk and cash flow. Transaction flow: credits vs debits, balances, branch and bank volumes, suspicious activity.

3. Tech Stack:
PowerBI - Main data visualization platform used for report creationg.
Power Query- Data transformation and cleaning layer for reshaping and preparing the data.
DAX - Used for calculated measures, dynamic visuals and conditional logics.
Data Modeling - Relationships established among tables to enable cross-filtering and aggregations.
File Format - .pbix for development and .png for dashboard preview.
